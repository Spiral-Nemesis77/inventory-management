Architecture overview

Factory Inventory Management System

A full-stack demo app for factory operations: inventory, orders, demand forecasts, backlog and spending. It's a Vue 3 single-page app talking to a FastAPI backend that serves in-memory data loaded from JSON files. There is no database.

Data flow

What happens when a user changes a filter, for example selecting a warehouse on the Dashboard.

  1. Filter changes in FilterBar

    Updates a module-level ref in useFilters. Because the refs live outside the function, every view shares the same filter state.

  2. The view reacts

    A watch in the active view calls getCurrentFilters(), which maps the UI names (period, location) to API names (month, warehouse).

  3. api.js builds the request

    Filters set to "all" are dropped, the rest become query params: /api/orders?warehouse=Tokyo&month=Q3-2025.

  4. FastAPI filters in memory

    apply_filters() does exact warehouse and case-insensitive category/status matches; filter_by_month() substring-matches order_date, expanding quarters through QUARTER_MAP.

  5. Pydantic validates the response

    Endpoints with a response_model are checked against the model; summary, spending and report endpoints return raw dicts.

  6. Computed properties render

    Raw data lands in refs; totals, chart series and currency formatting (USD, or JPY at a fixed 150 rate) are derived in computed().

Known gaps

Places where the frontend and backend disagree, found while mapping the code.

Broken Task endpoints don't exist

api.js calls GET/POST/PATCH/DELETE /api/tasks from App.vue, but the backend has no task routes, so these return 404.

Broken Purchase orders are half-built

api.js calls /api/purchase-orders (not implemented), and Dashboard.vue renders <PurchaseOrderModal>, a component that doesn't exist.

Inconsistent Filters don't reach every page

Demand, backlog, spending and reports endpoints ignore filters. The dashboard's backlog count is also unfiltered.

Inconsistent Reports bypasses api.js

Reports.vue calls axios directly with a hard-coded URL instead of going through the shared client.

Dead code Backlog view isn't routed

views/Backlog.vue exists but has no route in main.js or link in the nav.

Fragile Hard-coded 2025 quarters

QUARTER_MAP and the quarterly report only know 2025, and month matching is a substring check on the date string.
